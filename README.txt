OUR FIRST CHAPTER — KOKO ❤️

How to use:
1. Open index.html in your browser.
2. Replace the files inside images/ with your own photos:
   - memory-1.jpg through memory-6.jpg
3. Put your song in audio/ and name it:
   - our-song.mp3
4. If you want to change any text, open index.html.
5. If you want to change the letters, edit the "letters" object in script.js.

Everything is plain HTML/CSS/JavaScript — no framework needed.
